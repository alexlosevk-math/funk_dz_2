# Домашняя работа после раздела 4

Откройте `index.html`. Это самостоятельный статический сайт: для публикации загрузите **содержимое папки dz4** в корень отдельного сайта. Сборка, сервер и внешние библиотеки не требуются. Интернет для выполнения заданий не нужен.

Во вкладке «Функции» ровно 10 заданий по восьми семействам из раздела 4. Во вкладке «Теория 7–8» — 16 диагностических заданий: дроби и ограничения, линейные уравнения, системы, преобразования выражений, степени и корни, квадратные уравнения и неравенства. Типы: сопоставление, несколько ответов, числовые поля, порядок шагов, поиск ошибки, график с ползунком.

Предложите ученику выполнить сначала функции, затем после перерыва диагностику основ. Бумажные вычисления полезны. В диагностике сначала отвечать по памяти, затем обращаться к подсказке.

В «Моём результате» доступны копирование и скачивание отчёта. Учитываются первая попытка, уверенность, ошибки, подсказки и просмотр решения. После двух неверных попыток открывается разбор; после верного ответа объяснение доступно сразу. Правильность и самостоятельность следует обсуждать отдельно: ответы можно исправлять, а сайт не контролирует внешнюю помощь.

Данные остаются в localStorage браузера и не передаются учителю автоматически. Ответы сохраняются при переходе между заданиями и перезагрузке. На другом устройстве прогресс будет отдельным. Для новой диагностики сначала сохраните отчёт, затем нажмите «Начать заново».
